# 本地 IndexTTS2 陪看制作

这条流程只用于本机制作，不自动投稿。用户确认过的音色档案、语气参数和模型均保存在本机，不随仓库分发。

## 大肥鱼如何使用

1. `reaction_catalog` 查询已授权素材及已有任务。
2. `reaction_start(material_id, job_id, seconds, afterword)` 启动制作。`seconds=0` 表示看完授权范围，短样片可指定秒数；`afterword=true` 增加观后感。
3. `reaction_status(job_id)` 查询同一个任务；不要为了查询或重试另建任务。
4. 观看期间可用 `reaction_observation` 查看已看内容，按需要调用 `reaction_pause_analysis` 或 `reaction_replay`。后台陪看者同样能自主决定沉默、回应、暂停和表情动作。
5. 完成后从 status 的 `video` 和 `review` 取得成片、校验结果，交给用户审阅。

例如：“用授权的第一季01先做三分钟陪看，使用当前声音，什么时候开口和怎样表达由你决定，最后说说感想，完成后给我看，先不发布。”

## 制作过程

连续观看与配音分开。观看只接收已经到达的画面和带时间戳的听觉信息，记录沉默、反应、已说内容及表情动作。确定内容后再合成 IndexTTS2，不让合成耗时拖住剧情理解。

音色由确认过的参考音频固定；角色在确认过的 B 试听参数中选择语气。配音后按真实时长自行决定保留、缩短、取消或暂停分析。自然开口时间独立于字幕出现时间和网络耗时：角色依据已看证据选择理解完成和开始说话的时间，可以放弃发言，不统一添加固定延迟。

语音、字幕、口型及对应表情动作使用同一条输出时间轴。原片正常速度、原声音量保留，暂停分析期间暂停原片声画；大肥鱼语速不加速。片尾感想使用同一音色和角色上下文。

## 本机配置

原有配置增加 `voice_studio`：

```json
{
  "voice_studio": {
    "config": "本机音频模块配置的绝对路径",
    "python": "音频模块 Python 的绝对路径",
    "backend": "本机 video-studio/backend 的绝对路径",
    "reference": "voice-reference",
    "profile": "确认过的音色档案 JSON 的绝对路径",
    "autonomous_timing": true
  }
}
```

音色档案包含 `id`、`engine: "IndexTTS2"` 和 `presets`；每项包含 `id`、`direction` 和合法的八维 `emotion_vector`。音频模块配置提供参考素材、IndexTTS2 模型和转写模型路径。不得用任意路径替代已授权素材 ID。

新任务快照保存声音配置、参数与参考音频校验值。旧任务仍按原快照恢复；参考音频被改动时停止并要求重新确认。语音缓存按台词、上下文、配置和参考音频区分，避免不同语气误用缓存。

同一任务重复调用不重复启动；同一任务根目录只允许一个制作任务。异常保留进度，用原 ID 恢复。最终自动校验解码并保存 `review.json`，校验成功不代表用户已接受内容。没有投稿工具，不改人设、正式记忆、推理前缀或 B 站任务。

这是本地扩展，需要已有本机音频模块；不是独立安装即可运行的公开发布版。

## 通用交互试验（版本 4）

在独立任务配置中设置 `interaction_version: 4`。创建任务时快照保存此值；既有任务不切换算法。版本 3 仍是未指定时的行为。

版本 4 在制作目录内维护实体、关系、事件、疑问和预期。每项有稳定标识、证据时间、置信度和修订历史；它们是模型的理解，不等于事实核实。新证据更新原记录，不删除旧判断。展示给模型的工作摘要有容量边界，完整修订留在本地，正式人格记忆不被覆盖。

观察层更新这些记录，角色自己决定关注什么及是否开口。表达阶段使用当前经历、角色意图和近期发言，不直接照搬完整观察报告。播放工具由角色选择，不设定发言频率、固定情绪或句式。

配音后只检查语音重叠、素材结束边界等技术问题。没有冲突则保留原文和原选播放方式；有冲突交回角色安排、取消或重说。不会为了达到短句比例而例行缩写。此版本需通过同素材样片比较，再决定是否用于完整制作。
